Handy-Workflow

1. Startbild erstellen oder hochladen.
2. WAN 2.2 öffnen.
3. Bild + Prompt eingeben.
4. MP4 speichern.
5. Für einen neuen Clip einfach den nächsten Prompt verwenden.
